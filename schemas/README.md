# JSON Schemas

Machine-checkable shapes for Open Reason examples. Python validation lives in
`open_reason.validation` and `open_reason.models`.

| File | Use |
| --- | --- |
| `core.schema.json` | Every example |
| `provenance.schema.json` | Provenance, quality, verification |
| `coding.schema.json` | Coding extras |
| `reasoning.schema.json` | Reasoning extras |
| `science.schema.json` | Science extras |
| `mathematics.schema.json` | Math extras |
| `human.schema.json` | Human extras |
| `education.schema.json` | Curriculum fields (`concept_id`, `education_level`) |
