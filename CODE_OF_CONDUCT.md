# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in Open Reason a harassment-free experience for everyone.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language
- Being respectful of differing viewpoints
- Focusing on what is best for the research commons
- Showing empathy toward other contributors

Unacceptable behavior includes harassment, trolling, and publishing others' private information.

## Enforcement

Report issues to the maintainers via GitHub Security Advisories or the contact listed in `SECURITY.md`. Maintainers will review and take action they deem appropriate.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
