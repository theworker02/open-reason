# Taxonomy

Machine-readable vocabularies for domains, task types, verification methods,
and licenses. Generators and the dataset card should stay within these lists.

| File | Contents |
| --- | --- |
| `domains.yaml` | Domains, education levels, difficulty |
| `task_types.yaml` | Task types per configuration |
| `verification_methods.yaml` | Checkers that may set `quality.verified` |
| `licenses.yaml` | SPDX policy notes (NC/SA never relicensed to CC BY 4.0) |
