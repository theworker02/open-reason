# Contributing data and code

1. Never add Reddit or Reddit-derived material.
2. Do not fabricate provenance, licenses, or citations.
3. Do not mark examples verified unless a check in this repository ran.
4. Prefer a few excellent items over prompt paraphrases.
5. New sources need a `SourcePolicy` and a license review before they emit rows.
6. Coding tasks should ship with tests the sandbox can run.
7. Open a pull request against `main`.

See [CONTRIBUTING.md](../CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md).
